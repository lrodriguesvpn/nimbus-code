# Nimbus Code — Community (Lite Edition)

Este preset fornece a estrutura fundamental de **Spec-Driven Development (SDD)** para desenvolvedores e projetos que utilizam IA e agentes generativos no VS Code.

## O que está incluso na versão Community (Lite):
- Estrutura base de Especificação (SMART + BDD)
- Planejamento técnico simplificado (`plan-template.md`)
- Decomposição em tarefas acionáveis (`tasks-template.md`)
- Princípios fundamentais de governança em `constitution.md`
- Orquestrador de Triagem `@nimbus` Lite para condução inicial
