# Nimbus Code — Community Edition

Este preset fornece a estrutura fundamental de **Spec-Driven Development (SDD)** para projetos que utilizam IA e agentes generativos no VS Code.

## O que está incluso na versão Community:
- Estrutura de Especificação (SMART + BDD)
- Planejamento técnico simplificado
- Decomposição em tarefas acionáveis
- Princípios fundamentais de governança em `constitution.md`
