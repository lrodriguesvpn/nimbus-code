# Constituição do Projeto (Community Edition)

Este arquivo estabelece os princípios invioláveis de engenharia para o desenvolvimento deste repositório com suporte a agentes de IA.

## Princípios Não-Negociáveis
1. **Especificação Antes do Código**: Nenhuma linha de código deve ser escrita sem uma especificação (`spec.md`) e um plano (`plan.md`) prévios.
2. **Test-Driven Development (TDD)**: Testes unitários ou de integração devem acompanhar toda nova funcionalidade ou correção de bug.
3. **Segurança & Segredos**: Jamais comite senhas, tokens, credenciais ou chaves de API no repositório.
4. **Isolamento de Mudança**: Mantenha as alterações estritamente focadas no escopo definido para a tarefa.
5. **Transparência**: Toda decisão técnica com impacto arquitetural deve ser registrada no plano da funcionalidade.
