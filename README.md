Nimbus Code Lite e uma distribuicao local com codigo-fonte disponivel para
times e desenvolvedores que desejam estruturar a jornada entre ideia,
especificacao, planejamento, tarefas e validacao.

> **Lite e a porta de entrada.** Ele foi desenhado para aprendizado, avaliacao,
> testes nao produtivos e uso pessoal com praticas claras de engenharia.

## O que voce encontra no Lite

| Componente | Para que serve |
| --- | --- |
| **Extensao VS Code Lite** | Inicializa os artefatos essenciais de SDD no workspace. |
| **MCP Lite** | Disponibiliza templates locais de constituicao, especificacao, plano e tarefas. |
| **Preset Community** | Oferece os mesmos templates em Markdown para uso direto no repositorio. |

## Comece em minutos

### 1. Instale a extensao VS Code Lite

```bash
cd extensions/vscode
npm install
npm run compile
npm run package
```

Instale o arquivo `.vsix` gerado e execute **Nimbus Code Lite: Inicializar
Repositorio** pela Command Palette.

### 2. Ou conecte o MCP Lite

```bash
cd servers/mcp-nimbus
npm install
npm run build
node dist/index.js
```

O servidor expoe apenas os tools `nimbus_lite_get_template` e
`nimbus_lite_getting_started`.

### 3. Comece pelo metodo

Use os templates para registrar o problema, escrever a especificacao, planejar
a entrega e transformar o plano em tarefas verificaveis.
