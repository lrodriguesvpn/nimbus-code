# Guia para Claude Enterprise e ChatGPT

## Objetivo

Explicar como usuários que ainda dependem de Claude Enterprise ou ChatGPT
devem seguir a mesma constituição corporativa de IA.

## Regras

- Não existe uma política separada por ferramenta.
- Todo uso permitido precisa respeitar a constituição corporativa.
- Informações sensíveis continuam sujeitas às regras internas de acesso e
  compartilhamento.
- Se houver dúvida sobre a ferramenta oficial, a resposta padrão é:
  Microsoft Copilot para produtividade e GitHub Enterprise Copilot para
  engenharia.

## Quando usar

- Cenários de transição
- Usuários que ainda não migraram para as ferramentas oficiais
- Casos excepcionais aprovados pela empresa

## Quando não usar

- Para criar nova política de IA
- Para substituir a constituição corporativa
- Para justificar acesso a dados que o usuário não deveria ver

## Lembrete

Os nomes Nimbus seguem válidos no fluxo Spec Kit, mas são apenas aliases sobre
os comandos originais.
