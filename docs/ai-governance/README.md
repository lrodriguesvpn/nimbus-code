# Governança Corporativa de IA

Este índice reúne a constituição única da empresa para toda IA e os guias de
uso por ferramenta.

## Ferramentas oficiais

- **Microsoft Copilot**: ferramenta oficial para produtividade, colaboração e
  uso de negócio.
- **GitHub Enterprise Copilot**: ferramenta oficial para engenharia e entrega
  de software.

## Regras de uso

- A empresa mantém uma única constituição para toda IA.
- Qualquer agente criado no Microsoft 365 segue essa mesma constituição.
- Claude Enterprise e ChatGPT só podem ser usados sob a mesma constituição,
  sem criar política separada.
- Os nomes Nimbus são uma camada de aliases; os comandos originais do Spec Kit
  continuam válidos.
