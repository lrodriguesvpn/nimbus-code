# Aliases Nimbus para o Spec Kit

## Objetivo

Documentar a camada de nomes Nimbus sem alterar os comandos originais do Spec
Kit.

## Mapa de equivalência

| Nome Nimbus | Comando original |
|---|---|
| `nimbus.constitution` | `constitution` |
| `nimbus.discovery` | `specify` |
| `nimbus.refinement` | `clarify` |
| `nimbus.plan` | `plan` |
| `nimbus.backlog` | `tasks` |
| `nimbus.build` | `implement` |
| `nimbus.validate` | `analyze` |
| `nimbus.release` | `converge` |

## Regras

- Os aliases são uma camada de nomenclatura.
- Os comandos originais continuam válidos.
- A documentação deve citar o equivalente quando usar a nomenclatura Nimbus.
- Nenhum fluxo oficial deve depender exclusivamente do alias.

## Uso recomendado

Use os nomes Nimbus nas comunicações internas, mas mantenha o comando original
em instruções técnicas, automações e documentação de compatibilidade.
