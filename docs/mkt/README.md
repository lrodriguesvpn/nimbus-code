## Estrutura no Repositório Satélite (`nimbus-code-mkt`)

- **`pitch-decks/`**: Decks de apresentação executiva, script gerador em Python (`build_deck.py`) e apresentações PPTX oficiais.
- **`gtm/`**: Master Doc de Produto e Metodologia Nimbus Code, resumos de lançamento de versão e One-Pager executivo.
- **`sales-cadences/`**: Sequências completas de e-mails de outbound, follow-ups e roteiro de pitch de vendas.
- **`leadership/`**: Comunicação para comitês executivos e alinhamentos de diretoria.
- **`specs/`**: Especificações funcionais das campanhas, trilhas e ativações de marketing conduzidas via Nimbus Code.
